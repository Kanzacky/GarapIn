# GarapIn

Garap.in adalah aplikasi **Realtime Collaborative Task Management System** yang membantu tim mengatur pekerjaan, memantau progres proyek, dan berkolaborasi dalam satu ruang kerja digital.

Aplikasi ini dirancang untuk mendukung pengelolaan proyek berbasis Kanban Board, penugasan anggota tim, pelacakan status tugas, komentar, lampiran file, notifikasi real-time, activity log, dan dashboard monitoring.

## Key Features

- Real-time Kanban Board
- Project and Team Management
- Task Assignment and Status Tracking
- Comments and File Attachments
- Activity Log and Smart Notification
- Task Priority, Label, Watcher, and Dependency
- Communication Channel
- Dashboard Monitoring

## Tech Stack

- Frontend: Next.js / React
- Backend: Express.js / NestJS
- Database: MySQL / PostgreSQL
- Realtime: WebSocket / Socket.IO
- Authentication: JWT
